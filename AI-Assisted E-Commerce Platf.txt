Simple AI-Assisted E-Commerce Platform - PRD
1. Product Overview
Product Name

SmartCart

Description

SmartCart is a simple e-commerce web application that helps users browse, search, and purchase products online. The platform includes basic AI-assisted features like product recommendations and chatbot support to improve user experience.

The goal is to create a beginner-friendly but professional full-stack project suitable for placements and resume building.

2. Main Goals
Allow users to buy products online easily
Provide personalized product suggestions
Enable secure payments and order tracking
Build a responsive and user-friendly platform
Add basic AI functionality without overcomplicating the system
